# Privacy

## What leaves the machine

Nothing, unless `gemini.api_key` is set. There is no telemetry, no analytics
and no phone-home. The daemon makes no outbound connection at all in its
default configuration.

With AI analysis enabled, the current sample and recent logs are sent to Google
Gemini. Before they leave:

- IPv4 and IPv6 addresses are redacted
- E-mail addresses are redacted
- Home-directory usernames are redacted from paths
- Process names and the top-process summary go through the same scrubber

Redaction is applied server-side, in Go, on the single path that reaches the
model. An earlier build carried a second scrubber in the browser that was never
called and had drifted from the Go one — a security-audit liability, since the
weaker implementation was the one actually gating egress. It has been removed.

## What the AI is allowed to tell you

Recommended commands are **generated by a language model and are not validated
by the daemon**. The dashboard copies them to the clipboard; it never runs
them. The model self-declares whether a command is destructive, and the UI
labels it as the model's claim rather than a verdict, because it is one.

## Fonts and assets

Everything is bundled. The dashboard makes no request to any CDN, which matters
because this runs on air-gapped networks — and because a remote font link does
not fail loudly, it silently falls back, so the typography would quietly change
on exactly the deployments that matter.

## What is stored, and where

Metrics, AI insights, alert history, users and sessions live in one SQLite file
at `database.path`. Passwords are stored as argon2id hashes, never reversibly.

The file contains credentials, so back it up with `sys-daemon --backup`, which
writes it `0600`, rather than copying it — see [INSTALL.md](INSTALL.md) and
the note on `cp` in [PERFORMANCE.md](PERFORMANCE.md).

Retention is tiered; see [CONFIGURATION.md](CONFIGURATION.md#collection-and-storage).
